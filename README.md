# A Nose-Teeth-Based System for Users with Restricted Upper Limb Mobility

Research article from my B.Sc. thesis at MIST, Dhaka (2024).
A hands-free computer interface using MediaPipe FaceMesh and OpenCV,
evaluated in a 15-participant usability study.

Authors: Tajakka Binte Aziz, Marzan Samin Ashrafi, Md Afir Uddin Bhuiyan,
Lt Col Muhammad Nazrul Islam, Md. Abdus Sattar.
Status: unpublished manuscript. Article: thesis_article_B09.pdf
